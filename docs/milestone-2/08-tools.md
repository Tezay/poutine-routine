# Tools

| Artefact | Tool |
|:-----------------------|:----------------------------------------------------|
| Screens in this document | Screenshots of the running application, taken in the browser. The mockups of Milestone 1 stay in Figma |
| Frontend | Vue 3, Vite, Vue Router, Pinia and Tailwind CSS, with ESLint and Prettier |
| Pixel-art sprites | Drawn in Pixquare and exported as PNG images |
| Sidebar icons | [Lucide](https://lucide.dev), four SVG files copied into the project (ISC license) |
| Continuous integration | GitHub Actions: lint, format check and build on every pull request, and the GitHub Pages deployment after each merge |
| This document | Markdown files in `docs/milestone-2/`, converted to PDF with pandoc and the Typst engine |
| Source control | Git and GitHub, with issues, pull requests and a branch ruleset |
| AI assistants | We used AI assistants (Claude, Gemini) at several steps, as learning tools: to understand new notions and the course prerequisites, to learn standards such as accessibility, and to go deeper into topics. Every change went through a pull request, and each member can explain the code they submit |
